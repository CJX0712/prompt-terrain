> 把一段长 prompt 摊开成一条地形带，一眼看见它在哪里重复、重复了几次、值多少钱。

**单个 HTML 文件，零依赖，双击即用，完全离线。** 所有计算都在你的浏览器里完成，文本不会离开这台设备。

---

## 它解决什么问题

写长 system prompt 的人几乎都会遇到同一件事：写着写着，同一句话出现在了三个地方。可能是复制粘贴的样板条款，可能是两轮迭代后忘了删掉的旧约束，也可能是"再强调一遍"时顺手又写了一次。

这些重复很便宜地烧掉了两样东西：**上下文窗口**和**钱**。但如果 prompt 有 3000 字，你不会去逐字检查它。

PromptTerrain 做的就是这件事的自动化版本：给文本做一次"断层扫描"，把重复结构画出来，并估算去重之后能省下多少 token。

## 四层扫描带

界面右侧从上到下是四层共用一个横轴（= 文本位置）的图形：

| 层 | 名称 | 读法 |
|---|---|---|
| 1 | **Token 带** | 按字符类型着色（汉字 / 字母 / 数字 / 标点 / 空白）。每一竖列是文本的一个切片，颜色是该切片里占比最高的字符类型。用来感受文本的"质地"和密度分布。 |
| 2 | **冗余覆盖带** | 红色 = 该位置参与了至少一次重复。连续红条越宽，说明有一大段内容在别处也出现过。 |
| 3 | **冗余弧桥** | 同一个片段的多次出现之间连一条弧线。弧越高，两次出现相隔越远；弧越红越粗，重复次数越多。**散落在全文各处的小碎片重复**在这里最显眼。 |
| 4 | **信息熵地形** | 滑窗计算字符级香农熵并归一化到 0–1。山峰 = 信息密集；**谷底 = 模板化 / 套话 / 复制粘贴的区块**，红点标出了所有低于 0.55 的低谷。 |

鼠标在图上移动会显示该位置的字符、局部熵、是否重复、属于哪个片段；点击会直接跳到原文并高亮选中。

## 核心指标

- **冗余率** — 参与至少一次重复的字符数 ÷ 总字符数。注意这是"重复覆盖率"，不等于压缩率上限，但两者高度相关。
- **可省字符 / 可省 Token** — 每个片段出现 `k` 次、长度 `l`，则可省 `(k−1) × l` 字符，换算成 token 后累加。
- **重复片段列表** — 按"可省字符"降序排列，点击任意一行跳转定位。

## 算法

1. **归一化**：按选项忽略大小写 / 空白 / 标点，同时维护一张 `归一化下标 → 原文下标` 的映射表，保证结果能精确回指原文。
2. **n-gram 打标**：以长度 `n` 滑动取字符 n-gram，出现 ≥2 次的 n-gram 覆盖到的所有位置标记为重复；标记结果合并为连续区间。
3. **最小周期识别**：如果某个区间自身呈周期性（连续复制粘贴的产物，如 `abcabcabc`），用 **KMP 前缀函数**求出最小周期，以周期作为真正的重复单元 —— 否则整段只"出现一次"，反而检不出来。
4. **回映射 + 定位**：把区间映射回原文坐标，再用 `indexOf` 找出该单元的全部出现位置。
5. **熵地形**：窗口 `w`、步长 `w/6` 滑动，逐窗计算 `H = −Σ p·log₂p`，除以 `log₂(不同字符数)` 归一化。
6. **Token 估算**：汉字 1 token/字，拉丁字母 4 字符/token，数字 3 字符/token，标点 0.5 token/个。

整条链路是 O(n) 到 O(n·k)，几千字的 prompt 分析耗时在个位数毫秒。

## 参数

| 参数 | 默认 | 作用 |
|---|---|---|
| 检测粒度 n-gram | 10 | 越小越敏感、越容易抓到短重复；越大越保守 |
| 最小重复长度 | 8 | 低于此长度的重复片段不单独列出 |
| 熵窗口 | 80 | 影响地形平滑度；文本长时调大 |
| 预计输出 token | 500 | 仅用于成本估算 |
| 忽略大小写 / 空白 / 标点 | 开 / 开 / 关 | 归一化选项，会让检测更宽松 |

## 典型用法

- **瘦身 system prompt** — 找出被重复强调的条款，合并成一处引用。
- **审计 RAG 上下文** — 看召回的多段文档之间重叠多少，冗余率过高说明分块策略有问题。
- **代码 / 配置文件** — 粘贴进去找复制粘贴的样板块。
- **写作自检** — 长文里的车轱辘话在熵地形上是一条明显的低谷带。

## 已知局限

- Token 数是**保守估算**，不等于任何厂商的真实分词结果，用于预算评估而非精确计费。
- 冗余率衡量的是"字面重复"，语义重复（换个说法再说一遍）检测不出来。
- 成本表里的模型名、上下文窗口、单价都是**可编辑的示例占位值**，请按你实际使用的模型和当期定价自行修改；本项目不内置、也不保证任何定价数据的时效性。
- 超过 20 万字符时会关闭原文高亮以保证响应速度，统计与图形仍然有效。
